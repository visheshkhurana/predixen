### P1 — Logout does not end Express sessions

#134 revokes FastAPI sessions (logout, password reset, suspension) via `revoked_access_tokens` and `user_session_cutoffs`, checked in `get_current_user`. Express `requireAuth` only verifies the HS256 JWT and expiry. It does not read the revocation table.

```65:68:server/middleware/requireAuth.ts
export function requireAuth(req: Request, res: Response, next: NextFunction): void {
  if (!readAuthPayload(req, res)) return;
  next();
}
```

`/api/ai/*`, Notion, and messaging are Express-owned (`LOCAL_API_PREFIXES` in `server/index.ts`). A token presented after logout stays valid there until `ACCESS_TOKEN_EXPIRE_MINUTES` (8 hours). Tests in `server/tests/test_session_revocation.py` cover FastAPI only. If the revocation tables are missing at boot, FastAPI also skips the check rather than failing closed.
