Agent Communication Patterns

FounderConsole agents should use multiple orchestration patterns depending on the task:

Sequential Pipeline

Example:

CFO → Simulation → Strategy

Useful for structured workflows.

⸻

Parallel Analysis

Example:

Market Agent
CFO Agent
Simulation Agent

All run simultaneously.

Parallel execution speeds up complex analysis tasks.  ￼

⸻

Routing Pattern

The orchestrator routes tasks to specialized agents based on context.  ￼

Example:

pricing question → strategy agent
hiring question → CFO + simulation


⸻

Reflection / Verification Layer

Before presenting results, the system should run a review agent.

Purpose:

• detect hallucinations
• verify calculations
• check assumptions

Workflow:

agent output
↓
review agent
↓
final answer
