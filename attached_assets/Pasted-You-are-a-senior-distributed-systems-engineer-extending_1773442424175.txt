You are a senior distributed systems engineer extending the FounderConsole platform.

Your task is to implement the **Founder Intelligence Graph**.

The Founder Intelligence Graph connects:

• companies
• founders
• metrics
• decisions
• strategies
• outcomes

This graph allows FounderConsole to analyze cross-company patterns and generate strategic insights.

The graph must integrate with the existing:

• Digital Twin architecture
• Event Ledger
• AI agents
• Simulation engine

STEP 7 — BUILD SIMILARITY ENGINE

Create service:

services/graph/similarityService.ts

Purpose:

find companies similar to the current company.

Similarity criteria:

MRR range
growth rate
team size
industry

Example Cypher query:

MATCH (c:Company)
WHERE c.mrr > $minMRR
AND c.mrr < $maxMRR
AND c.industry = $industry
RETURN c

--------------------------------------------------

STEP 8 — ADD GRAPH INTELLIGENCE QUERIES

Create API:

/api/graph/insights

Example queries:

1. Find strategies used by successful companies

MATCH (c:Company)-[:USED_STRATEGY]->(s:Strategy)
WHERE c.growth_rate > 0.15
RETURN s, count(*)

2. Find most common decisions

MATCH (d:Decision)
RETURN d.decision_type, count(*)

3. Find outcomes of hiring decisions

MATCH (d:Decision)-[:RESULTED_IN]->(o:Outcome)
WHERE d.decision_type = "hire_engineers"
RETURN o
